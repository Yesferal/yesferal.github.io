# Best albums — how to update

Personal year rankings for HornsApp. **Public URLs:**

- Index: `https://yesferal.com/hornsapp/best/album/`
- Year: `https://yesferal.com/hornsapp/best/album/<year>/`

## Source of truth

**`album/catalog.json` is enough.** That is what the site (and CI) use.

| File | Track in git? | Role |
|------|---------------|------|
| `album/catalog.json` | **Yes** | Source of truth for pages |
| `scripts/hornsapp/data/best-albums.csv` | No (gitignored) | Optional Sheet export for re-import |
| `album/<year>/` + `album/index.html` | No (gitignored) | Generated by sync; CI rebuilds on deploy |

Rules in the generator:

- Ranks **1–6** → main “Top” list  
- Ranks **7+** and **B** → “Bonus”  
- `Have It` → “owned” badge  

## Update from Google Sheets

1. Sheet → **File → Download → Comma Separated Values (.csv)**.
2. Save it here (overwrite is fine):

   `scripts/hornsapp/data/best-albums.csv`

   Or keep it in Downloads and pass that path in step 3.
3. From the **repo root**, import then sync:

```bash
python3 scripts/hornsapp/import-best-albums-csv.py scripts/hornsapp/data/best-albums.csv
python3 scripts/hornsapp/sync-best-albums.py
```

   (If the file is elsewhere:  
   `python3 scripts/hornsapp/import-best-albums-csv.py ~/Downloads/YourExport.csv`  
   then the same `sync-best-albums.py`.)

4. Spot-check 1–2 years locally (optional):

```bash
python3 -m http.server 8766
# http://127.0.0.1:8766/hornsapp/best/album/
```

5. Commit **only `album/catalog.json`** (plus CSS/README if you changed those). Push `main` — Actions runs sync again and deploys.

That’s it. You do **not** need to commit the CSV or the year HTML.

## Quick edit without the sheet

Edit `album/catalog.json` directly, then:

```bash
python3 scripts/hornsapp/sync-best-albums.py
```

Commit `catalog.json` and push.

## Scripts

| Script | Does |
|--------|------|
| `scripts/hornsapp/import-best-albums-csv.py` | CSV → `catalog.json` |
| `scripts/hornsapp/sync-best-albums.py` | `catalog.json` → index + year pages |
